# Desktop Organizer v1.0.0

This is the first public release of Desktop Organizer for Windows 10 and Windows 11.

## Included

The release contains a self-contained `DesktopOrganizer.exe` built with Python 3.12 and PyInstaller. It includes the dark Tkinter interface, preview-only organization, dated archive folders, conservative folder handling, extension/name exclusions, Windows startup registration, hidden startup mode, system tray controls, automatic notifications, up to three schedule slots, daily/weekday/custom-day repetition, missed-run handling, and backward-compatible JSON configuration.

## Installation

Download `DesktopOrganizer.exe`, save it to a permanent folder, and run it. Open **Settings** before the first run, then use **Preview only** on the Run tab to review the planned operation. Full instructions are available in the repository README and the `docs` folder.

## Verification

The executable is a 64-bit Windows GUI PE binary. Verify the downloaded file with the SHA-256 value in `SHA256SUMS.txt`.
