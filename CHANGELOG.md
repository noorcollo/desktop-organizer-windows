# Changelog

All notable user-visible changes to Desktop Organizer are documented here.

## [1.0.0] - 2026-08-21

### Added

- Dark Tkinter interface with Run, Settings, and Log tabs.
- Manual organization for yesterday, today, or a custom date.
- Preview-only mode that moves nothing.
- Dated archive folders with collision-safe numbered names.
- Conservative folder handling based on creation date.
- Extension and name-pattern exclusions.
- Up to three schedule slots with daily, weekday, and custom-day repetition.
- Missed-schedule handling on application startup.
- Windows startup registration with hidden startup mode.
- System tray icon with Open, Run Now, next-run display, and Exit actions.
- Automatic-run tray notifications.
- Backward-compatible JSON configuration at `~/.desktop_organizer_config.json`.
- PyInstaller one-file Windows build and GitHub Actions packaging workflow.
